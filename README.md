## 🛠️ Tech Stack

This website is a **fully-static Next.js 15** site deployed on **Cloudflare Pages** for zero-latency global delivery.

| Technology | Purpose |
|-----------|---------|
| **Next.js 15** (App Router) | SSG static export — all pages pre-built |
| **React 19** | UI components |
| **TypeScript** | Type-safe codebase |
| **Tailwind CSS 4** | Utility-first styling |
| **Cloudflare Pages** | Global CDN hosting (free tier, unlimited static) |
| **next/font/google** | Self-hosted Syne + Inter — no render-blocking |
| **Schema.org JSON-LD** | Rich results: AggregateRating, FAQ, BreadcrumbList, LocalBusiness |
| **Wrangler** | Cloudflare deployment CLI |
| **GitHub Actions** | CI/CD pipeline — push to `main` → auto-deploy |

## 💻 Local Development

### Prerequisites
- Node.js 22+
- npm 10+

### Setup

```bash
# Clone the repository
git clone https://github.com/kolkatacabtaxiservices/nk-cab-taxi.git
cd nk-cab-taxi

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

### Available Scripts

```bash
npm run dev          # Start dev server (hot reload)
npm run build        # Standard Next.js build
npm run build:cf     # Full Cloudflare build pipeline (generates sitemaps + static files)
npm run deploy       # Deploy to Cloudflare Pages via Wrangler
npm run lint         # ESLint check
```

## ☁️ Cloudflare Pages Deployment

### Method 1: GitHub Actions (Recommended — Auto-deploy on push)

The `.github/workflows/deploy.yml` automatically builds and deploys on every push to `main`.

**Required GitHub Secrets** (Settings → Secrets → Actions):

| Secret | How to get it |
|--------|--------------|
| `CF_API_TOKEN` | Cloudflare Dashboard → My Profile → API Tokens → Create Token → **Edit Cloudflare Workers** template |
| `CF_ACCOUNT_ID` | Cloudflare Dashboard → Right sidebar → **Account ID** |

Once set, push to `main` triggers automatic deploy.

### Method 2: Manual CLI Deploy

```bash
# Install Wrangler
npm install -g wrangler

# Authenticate
wrangler login

# Build
npm run build:cf

# Deploy
npm run deploy
# or: wrangler pages deploy out --project-name=nk-cab-taxi
```

### Environment Variables for Cloudflare

Set these in **Cloudflare Dashboard → Pages → nk-cab-taxi → Settings → Environment Variables**:

| Variable | Value | Environment |
|----------|-------|-------------|
| `NEXT_PUBLIC_SITE_URL` | `https://www.nkcabtaxi.com` | Production + Preview |
| `NODE_ENV` | `production` | Production |
| `GOOGLE_SCRIPT_URL` | Your Google Apps Script URL (optional) | Production |

> **Note:** This is a static export — most config lives in `src/lib/data.ts` (BUSINESS constant). No runtime environment variables are needed for the site to function.
